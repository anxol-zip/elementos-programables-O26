# Elementos Programables I

Prácticas y ejercicios de la materia Elementos Programables I — Ingeniería en Sistemas Computacionales,
Universidad Iberoamericana Puebla, Otoño 2026. Angel Rugerio Jiménez #201720.

Todo está escrito en C sobre el Pico SDK para Raspberry Pi Pico (RP2040 / Pico 2 W), con simulación en
Wokwi donde aplica.

## Contenido

| Carpeta | Tema |
| ------- | ---- |
| [`practica01/`](practica01/) | Semáforo de dos vías, simulado en Wokwi |
| [`practica02/`](practica02/) | Máquina de estados de dos semáforos con botones peatonales |
| [`practica03/`](practica03/) | Monitor interactivo del RP2040 y exploración del SIO |
| [`ejercicio_p3/`](ejercicio_p3/) | Monitor de la Práctica 3 extendido con comandos de TIMER e interrupciones |

Cada carpeta tiene su propio código, `CMakeLists.txt` y documentación de la entrega.
